# Car Rent – C++ Application

A comprehensive Car Rental Management System developed in C++ that demonstrates Object-Oriented Programming, file handling, and real-world system design principles. The application streamlines vehicle management, rental operations, maintenance tracking, and cost calculations through an interactive menu-driven interface.

## Key Features

* Manage vehicle inventory with functionalities to add, search, rent, and return cars.
* Monitor vehicle availability, rental rates, mileage, and maintenance status.
* Maintain service records and track the latest maintenance activities.
* Automatically calculate rental charges based on rental duration.
* Store and retrieve vehicle information using file handling for persistent data management.
* Implement OOP concepts such as inheritance, encapsulation, and class-based design through Car and MaintainedCar classes.

## Project Setup

1. Clone the repository:

```bash
git clone https://github.com/BhargavDevi/car_rent.git
cd car_rent
```

2. Compile the project:

```bash
clang++ -o car_rental car.cpp
# OR
g++ -o car_rental car.cpp
```

3. Run the application:

```bash
./car_rental
```
